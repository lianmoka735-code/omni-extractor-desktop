# ⚡ 万能萃取助手 - Windows 桌面电脑客户端 (OmniExtractor Desktop)

> 本客户端是专为 **PC 电脑端 (Windows)** 设计的独立桌面软件。完全放弃小程序方案，采用原生桌面窗口架构（Electron + 现代深色科技 UI），免去微信公众平台审核与网络域名的限制，支持无限制的本地剪贴板监控、多媒体直接下载至电脑磁盘、大屏双栏高效解析以及快捷键操作。

---

## 🌟 电脑桌面版独占功能亮点

1. **原生电脑窗口体验**：
   - 支持自由缩放、最大化/最小化、流畅拖拽；
   - 现代深海蓝黑极简科技质感，长时间使用不疲劳。
2. **桌面级快捷操作**：
   - **`Ctrl + Enter`**：一键开始提取解析；
   - **`Ctrl + L`**：一键清空输入框；
   - **一键读取剪贴板**：点击【📋 粘贴剪贴板】按钮直接从系统剪贴板读取并填入。
3. **多媒体直接保存到电脑**：
   - 提取到的公开视频、音频与高清封面图，支持点击【保存到电脑】直接唤起系统保存文件对话框，将媒体文件保存至任意磁盘目录；
   - 支持直接在默认浏览器中打开原网页。
4. **本地历史记录抽屉**：
   - 每次提取的记录自动持久化保存在本地数据文件 (`data/history.json`) 中；
   - 侧边滑出抽屉，支持一键载入重新提取、复制原链接、单条删除与全部清空。
5. **SSRF 安全防护与个人信息脱敏**：
   - 内置安全过滤机制，坚决拦截针对局域网（`127.0.0.1`, `192.168.x.x`, `10.x.x.x`）的非法内网探测；
   - 自动针对文本中的手机号、私人电子邮箱进行掩码脱敏。

## 💻 快速运行方式

### 方式一：双击启动（最简单）
在电脑文件资源管理器中打开项目文件夹，直接双击运行：
👉 **[`start.bat`](file:///D:/软件/万能萃取助手/start.bat)**
即可立即启动桌面窗口！

### 方式二：命令行启动
```powershell
# 进入桌面端目录
cd "D:\软件\万能萃取助手"

# 启动桌面端应用
npm start
```

---

## 📦 打包成独立 Windows 安装包 (.exe)

如果需要将该应用分发为独立的 Windows 安装包或绿色免安装单文件：
```powershell
npm run dist
```
打包成功后，将在 `dist/` 目录下生成 `OmniExtractor-Setup-1.0.0.exe`。

## 📂 桌面端工程目录结构

```text
omni-extractor-desktop/
├── main.js                  # Electron 主进程 (创建窗口、IPC 通信、下载到本地)
├── preload.js               # 安全沙箱预加载桥接脚本
├── package.json             # 桌面端依赖与打包配置
├── start.bat                # Windows 一键启动脚本
├── data/                    # 本地数据持久化目录
│   └── history.json         # 本地历史记录
├── src/
│   ├── services/
│   │   ├── extractorService.js  # 核心公开网页与多媒体提取引擎
│   │   ├── security.js          # SSRF 安全防护与数据脱敏模块
│   │   └── storageService.js   # 本地文件持久化服务
│   └── renderer/            # 桌面前端 UI 视图层
│       ├── index.html       # 桌面端主界面布局
│       ├── style.css        # 现代桌面暗黑科技质感样式
│       └── app.js           # 桌面端交互控制器与快捷键绑定
└── README.md                # 桌面版使用说明
```
